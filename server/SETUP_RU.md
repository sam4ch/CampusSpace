# Сервер PAM — этап запуска шаблона L5

Источник: `PAM - BackEnd (project example)-20261110.zip`, вложение `dart.zip`.
Выбран эталонный порт Dart + Shelf с SQLite. Исходные `bin/server.dart`
и `lib/*.dart` сохранены без изменения. Служебные файлы macOS и чужой
`.dart_tool` не переносились; зависимости получены заново для этого компьютера.

## Запуск на Windows

```powershell
cd C:\Users\SamirPula\campus_space\server
dart pub get
.\start.ps1
```

Терминал оставить открытым. Остановка — Ctrl+C. По умолчанию порт 8080;
можно использовать `./start.ps1 -Port 8081`. Данные находятся в `app.db`,
файлы в `uploads/`; они исключены из Git.

Для sqlite3 2.x на Windows нужна библиотека `sqlite3.dll` той же архитектуры,
что и Dart. На этом компьютере x64 DLL уже помещена в `server/.local/`
из установленной среды Python (каталог DLLs). Это локальная зависимость,
она не включается в Git. `start.ps1` временно добавляет этот каталог в PATH.
На другом компьютере нужно установить подходящую sqlite3.dll из официального
дистрибутива SQLite или указать каталог существующей библиотеки:

```powershell
.\start.ps1 -SqliteDirectory C:\tools\sqlite
```

Если SQLite уже доступна через PATH, достаточно `dart run bin/server.dart`.
В среде автоматической проверки использован прямой запуск
`dart bin/server.dart` с установленным SDK и временным каталогом рабочего задания.

## Проверки

Второй терминал:

```powershell
cd C:\Users\SamirPula\campus_space\server
curl.exe -i http://localhost:8080/health
curl.exe -i http://localhost:8080/notes
dart tool/smoke_test.dart
```

Ожидается: `/health` — 200 и `{"status":"ok"}`, `/notes` без JWT — 401.
Дополнительный smoke-тест прошёл **25 проверок** 11.11.2026: auth, ошибки,
CRUD, ID сервера, поиск на кириллице, пагинация, изоляция пользователей.
Он создаёт двух тестовых пользователей с уникальными email и удаляет созданную
заметку. Тестовые пользователи остаются в локальной базе.

**Это не набор соответствия курса.** В архиве нет общих `openapi.yaml` и
`conformance/`, хотя исходный README ссылается на них через `../`.
Результат `37/37` не заявляется. Для обязательного доказательства в отчёте L5
нужно получить эти два компонента у преподавателя и выполнить официальный набор
сначала на базовом, затем на расширенном сервере.

## Доступные маршруты

| Метод | Путь | Назначение |
|---|---|---|
| GET | /health | Проверка запуска |
| POST | /auth/register | Регистрация: email, password, name |
| POST | /auth/login | Вход: email, password |
| GET | /me | Текущий пользователь, JWT |
| GET/POST | /notes | Список и создание, JWT |
| GET/PUT/DELETE | /notes/{id} | Операции с заметкой, JWT |
| POST | /files | Загрузка multipart, JWT |
| GET | /files/{id} | Получение файла |

Запросы списка поддерживают `page`, `limit`, `search`. Регистрация возвращает
JWT; защищённые маршруты принимают `Authorization: Bearer <token>`.
Upload/download присутствуют в шаблоне, но в указанные 25 smoke-проверок не входят.

Сущности CampusSpace пока не добавлены. Flutter-приложение по-прежнему
использует mock L4, поэтому запуск этого сервера ещё не подключает его к приложению.
Следующий этап — помещения, бронирования и избранное с сохранением базового контракта.
