# CampusSpace
CampusSpace — мобильное приложение для поиска и бронирования свободных аудиторий, переговорных комнат и лабораторий университета.

## Backend L5

Выбран эталонный порт **Dart + Shelf / SQLite** из архива преподавателя.
Исходный шаблон находится в `server/`, инструкция для Windows —
[server/SETUP_RU.md](server/SETUP_RU.md). На этом этапе добавлен базовый
сервер; сущности CampusSpace и HTTP-интеграция приложения ещё не подключены.
